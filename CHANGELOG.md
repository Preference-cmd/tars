## [Unreleased]

### Added

- **TUI zero-friction startup, `-c`/`--continue`, `-r`/`--resume [SELECTOR]`, `--workspace`, and `/clear` / `/resume` / `/model`**: Interactive `tars` now accepts `-c`/`--continue`, `-r`/`--resume [SELECTOR]`, and `--workspace DIR` in any order (preserving `-p`/`--print` routing precedence), automatically creates and opens a workspace-bound session with dynamic sandbox tools when a default profile is configured (degrading safely on missing credentials while preserving `--no-config` isolation and first-run onboarding), and adds `/clear`, `/resume [selector]` (backed by fresh `list()` + `resolve_session_selector_from_listings`), and `/model [profile]` (`Panel::Models` + `Tab` completion, creating new sessions without mutating existing `SessionDefinition`s).
- **TUI centralized minimalist theme, left-rail tool cards, inline diffs, and `Ctrl-O`**: Added `crates/tui/src/render/theme.rs` (`ACCENT = Color::Cyan`, `MUTED`/`OK`/`ERR`/`WARN`, emoji-free geometric glyphs `◇`/`▸`/`✓`/`✗`/`?`/`○`/`  │ `), paired committed `ToolCall`+`ToolResult` batches into compact left-rail cards with inline `edit_file` / created `write_file` diffs (`MAX_INLINE_DIFF_LINES = 12`, zero workspace disk reads, preserving `spilled preview`/`cleared preview` notices and omitting raw UUIDs from the main view while keeping full materials in `Ctrl-O`/`F6`/`/tools`), and upgraded live `ToolView` rows with `SPINNER_FRAMES` and `Clock`-frozen elapsed timers.
- **TUI live activity strip, compact Chrome, and `◇` thinking indicator**: Replaced `💭` with `◇` in streaming reasoning previews, added a 100 ms tick-driven live activity strip (`◇ Thinking`, `⠋ Running <tool>`, `⠋ Generating` with elapsed timer and zero redraws while idle), compressed the header to 1–2 rows displaying shortened `workspace_root`, and aligned the 4-row base footer (`Running` / permission mode highlighting and display-width truncation).
- **TUI scroll protection, unread output indicator, and fine-grained keyboard scroll**: Preserved scrolled reading position across streaming deltas, material refreshes, and turn completion (`↓ New output · End/PgDn` / `↑ Scrolled (X%) · End to follow`), kept terminal mouse capture off for native text selection, and added `Alt-↑/↓`, `Shift-↑/↓` (3 lines), `Alt-U/D` (half-page), and `Ctrl-Home/End` (plus empty-draft `Home/End`) bindings.
- **TUI `/copy` command and zero-dependency OSC 52 clipboard**: Added `/copy` (last non-empty assistant reply, skipping `Sealed`-only blocks and supporting read-only child-agent views and multi-segment transcript fallback), `/copy code [N]` (1-based fenced code block extraction via `pulldown-cmark`), and `/copy id` (full `conversation_id`, including unopened entries), backed by pure-Rust RFC 4648 Base64 OSC 52 output with automatic `$TMUX` DCS passthrough, `1 MiB` raw payload enforcement, `Tab` subcommand completion, and an injectable test sink.
- **Headless print mode (`tars -p` / `--print`)**: Added a `claude -p`-style headless entry point supporting positional prompts, `--` separator for leading-dash prompts, automatic non-TTY piped `stdin` reading and prompt combination (`"<prompt>\n\n<stdin>"`), automatic interactive stdio approval isolation whenever piped `stdin` is consumed, and persistent continuation via `-c`/`--continue` or `--resume <id|prefix|latest>` (with `--store` / `--no-config` isolation and strict flag-compatibility checks), while preserving bare non-TTY `tars` help behavior and `tars run` backward compatibility.
- **CLI streaming text & NDJSON output (`--stream`, `--stream-json`, `--output-format`)**: Added `OutputFormat` across `tars -p`, `tars run`, and `tars session run` supporting `--stream` (live `ProgressUpdate::Text` deltas on `stdout`, `\n\n` multi-turn separators, pre-`ModelOutputReady` retry notices, and escaped tool/compaction/agent status on `stderr`) and `--stream-json` / `--output-format stream-json` (compact NDJSON events on `stdout` ending with a `result` object preserving all `--json` fields, including on early failures), with mutual-exclusivity conflict detection and unchanged `--json` single-object contracts.
- **Read-only CLI diagnostics (`tars doctor`)**: Exposed `tars_core::doctor::run_diagnostics` as `tars doctor [--config <file> | --no-config] [--profile <name>] [--store <dir>] [--recovery-dir <dir>] [--workspace <dir>] [--json]` with zero network requests, no secret-value echoing, and deterministic exit codes (`0` when `fail == 0`, `1` on diagnostic failure/runtime error, `2` on invalid arguments).
- **Short-ID prefix & `latest` session selector resolution**: Added `SessionHost::resolve_session_selector`, `resolve_session_selector_from_listings`, and `SessionSelectorError` (`EmptySelector`, `NotFound`, `Ambiguous` with up to 5 ranked candidates) following exact ID -> lowercase `latest` -> ASCII case-insensitive unique prefix priority across all `tars session` ID-taking subcommands and `tars -p --resume`.
- **GFM Markdown conversation export (`tars_core::export`, `session export-markdown`, TUI `/export-md`)**: Added `tars_core::export` (`render_conversation_markdown`, `MarkdownExportOptions`, dynamic `safe_backtick_fence` preventing nested fence breakouts, default `tars:prelude:*` & `ToolChange` skipping, sanitized media summaries, and `ReplaceMode::CreateNew` `save_markdown_new`), `ManagedSession::expanded_agent_conversation` for root or child agents, CLI `tars session export-markdown` (`--agent`, `--last N`, `--output`, `--json`), and non-blocking TUI `/export-md [path]` (defaulting to `<recovery_dir>/tars-export-<short-id>-<timestamp>.md` or `<recovery_dir>/tars-export-<short-id>-<agent-slug>-<timestamp>.md` for child agents without overwriting existing files).
- **Precise CLI argument diagnostics, per-subcommand `--help`, and `tars completions`**: Replaced generic CLI parser rejections with flag-specific diagnostics (unknown, duplicate, missing/empty value, inapplicable subcommand option, and mutual exclusion), added dedicated `--help` / `-h` output for `-p`, `run`, `doctor`, `completions`, `tools` subcommands, and all 13 `tars session` subcommands, and added zero-dependency static shell completion generation via `tars completions <bash|zsh|fish>`.

- **TUI rich-text GFM Markdown rendering (`pulldown-cmark` 0.13, `default-features = false`)**: Committed `Role::Assistant` messages (in the active transcript, expanded compaction history, and `/agents` read-only child views) render headings (`H1`–`H6`), nested inline styles (`bold`, `italic`, `strikethrough`, `code`), deduplicated links & image fallbacks, ordered/unordered/task lists with hanging-indent wrapping, nested blockquotes, adaptive horizontal rules, dynamic-width boxed tables (degrading cleanly to stacked cards below 20 columns), and framed code blocks using terminal-neutral styling, while isolating user prompts, tool summaries, system blocks, and raw XML as plain text and preserving `Rows` blocking-pool caching, `ScrollAnchor` stability, `O(1)` tail streaming `Preview`, and double-boundary untrusted text escaping.
- **Pure-Rust single-pass lexical syntax highlighter**: Zero-unsafe `O(n)` code-block and diff highlighter supporting 11 language groups (`rust`/`rs`, `typescript`/`ts`/`tsx`/`javascript`/`js`/`jsx`, `python`/`py`, `go`, `sh`/`bash`/`zsh`/`shell`, `json`/`jsonc`, `toml`, `yaml`/`yml`, `sql`, `c`/`cpp`/`c++`/`h`/`hpp`, and `diff`/`patch`), falling back linearly to plain text for unknown languages or blocks over `64 KiB`.
- **`/tools` & `/summary` detail panel readability**: `/tools` (F6) colors record headers and structurally expands and highlights unified diffs embedded in `write_file`/`edit_file` outputs (including lazily loaded spilled artifacts, immune to string-prefix spoofing) while staying strictly read-only; `/summary` renders the context summary chain as GFM Markdown.
- **Core & CLI session lifecycle (`rename`, `delete`, `fork`)**: Added `validate_session_title` (`MAX_SESSION_TITLE_CHARS = 160`, control-char rejection, explicit clear suppressing auto-derived titles), `SessionStore::{rename_session, delete_session, fork_session_with_lock_check}`, `ManagedSession::rename` (with in-flight save/compaction/close reconciliation), `SessionHost::{rename, delete, fork}`, and `tars session {rename, delete, fork}` CLI subcommands (`--json` included); `delete` unbinds `operations.parent_operation_id` for nested multi-agent cleanup while preserving `workspace_trust`, and `fork` creates physically isolated revision-1 clones (rewriting `HistoryRecord.conversation_id`, copying entry `artifacts`, resetting usage, and downgrading non-initial runtime `full-access` to `ask`) protected by `ForkGuard`.
- **TUI running-turn FIFO prompt queue & `/queue`**: Added per-session in-memory prompt queuing (`MAX_QUEUED_PROMPTS = 8`) during active turns with escaped footer preview (`Queued (N): <preview>`), automatic FIFO submission only after clean `completed` + saved + repair-free turns (without duplicating `input_history`), strict pause on cancellation/failure/timeout/`SaveBlocked`/needs-`/repair`, `/queue [list | pop | clear]`, and `/close`/`/quit` confirmation protection.
- **TUI `/rename`, `/fork`, and `/sessions` safe delete**: Added `/rename <title>` / `/rename --clear`, `/fork [title]` (opening and switching to the isolated fork while keeping the original intact), and `Ctrl-D` / `Delete` inside `/sessions` with `y`/`n` confirmation for unopened sessions (while keeping printable characters bound to `query` filtering).
- **TUI external `$EDITOR` editing (`Ctrl-G` / `/edit`)**: Resolves `$VISUAL` then `$EDITOR` without guessing fallbacks, tokenizes quotes/escapes and spawns directly via `Command::new` (no `sh -c`) against an exclusive `.md` temporary file closed before spawn, explicitly drops/recreates `EventStream` with unconditional terminal restoration, and enforces a `1 MiB` UTF-8 import limit while preserving the draft on errors or non-zero exits.
- **Core multimodal image input, zero-migration SQLite persistence & sidecar export (`tars_core::media`)**: Added magic-byte-verified image ingestion (`PNG`, `JPEG`, `GIF`, `WebP`; bounds `5 MiB`/image, `8`/message, `64 MiB`/session) with `media:sha256:<64hex>` content addressing, `MediaVault` (`MediaResolver` serving both user images and MCP `ToolResult.media` `artifact:<uuid>` blobs), `ManagedSession::submit_with_images` (supporting text + image and image-only turns), atomic `INSERT OR IGNORE` persistence into `artifacts` inside `Writer::commit` (`SCHEMA_VERSION = 1` unchanged), fail-closed reopen digest/magic verification, fork isolation & compaction/cleanup preservation, `GATEWAY_INLINE_IMAGE_LIMIT_BYTES = MAX_IMAGE_BYTES + 3` preserving exact `5 MiB` inline images while omitting raw image bytes on compaction summary calls, and sidecar `.media/` export/load (`export_session_materials`, `save_new_with_media`, `load_with_media`).
- **CLI multimodal `--image` & sidecar reporting**: Added repeatable `--image <PATH>` to `tars run` and `tars session run` (allowing text + images or image-only submissions), sanitized media summaries in `tars session history` (`--json` preserving native structures), and `.media/` sidecar export reporting in `tars session export-materials`.
- **TUI `/image`, paste/drag-and-drop detection & image queue**: Added `/image [<path> | remove <n> | clear]` (with `Tab` local path completion), automatic `Event::Paste` local image path detection (supporting quotes and backslash escapes with lossless plain-text fallback), `QueuedPrompt` (`VecDeque<QueuedPrompt>`) running-turn queuing with `/queue pop` restoration and `[N image(s)]` preview badges, a height-aware composer `Images:` attachment bar included in `has_draft()` close/quit guards, and control-escaped media badges in `Transcript` and `HistoryView`.

## [0.1.0] - 2026-11-26

### Added

- **Unified `tars` binary & TUI UX**: Single `tars` entry point combining interactive terminal mode (first-run setup wizard, `/doctor`, `/init`, `/new`, `/sessions`, `/agents`, `/mode`, `/compact`, `/summary`, `/tools`, `/status`, `/help`) with scriptable CLI subcommands (`run`, `session`, `tools`).
- **Multi-protocol `causa 0.3` runtime**: Support for `openai-chat`, `openai-responses`, and `anthropic` protocols with custom endpoints, environment-variable-only API keys, prompt caching (`CacheDirective::StablePrefix`), and bounded pre-`Done` mid-stream transient retry.
- **Workspace tools & platform sandboxing**: Built-in `list_directory`, `read_file`, `find_files` (`.gitignore`/`.ignore`-aware BFS discovery), `search_text`, `write_file`, `edit_file`, and `run_command` behind four permission modes (`read-only`, `ask`, `accept-edits`, `full-access`), read-before-write guards, layered command rules, macOS Seatbelt, and Linux Bubblewrap (`bwrap`) + `seccomp-BPF` sandboxes.
- **Consent-gated external `rg` resolution**: Default `[external_tools] rg = "auto"` checks a SHA-256-verified managed copy first, falls back to compatible `rg >= 14` on `PATH`, and prompts before downloading pinned ripgrep `15.2.0`.
- **Long-session compaction & recall**: Automatic and manual LLM summarization, zero-LLM micro-compaction (`micro-compact`) with cache-safety gates, temporary frame trimming fallback, persistent `recall` tool, and history expansion.
- **SQLite v3 store & multi-agent collaboration**: Embedded WAL SQLite store (`tars.db`) with OS advisory locks, `import-legacy` for `tars-session-v2.4` JSON files, unified prelude + multi-directory `load_skill` skills, and event-driven sub-agent delegation (`spawn_agent`, `message_agent`, `read_agent`, `cancel_agent`) with monotonic narrowing and `.tars/agents/*.md` workspace trust.
- **Opt-in programmatic tool calling (`run_code`)**: Sandboxed ES2020 QuickJS runtime for read-only multi-step orchestration across workspace tools, `recall`, and read-only MCP tools.
- **MCP client support**: Standalone `mcp.json` configuration with `${VAR}` expansion, stdio/HTTP transports, `McpToolAnnotations` classification, and per-tool approval policy.
- **Release pipeline & POSIX installer**: Added `[profile.dist]` in `Cargo.toml`, `.github/workflows/release.yml` (4-target native builds with `ubuntu:22.04` container glibc 2.35 baseline on Linux, whitelist archive checks, `SHA256SUMS.txt`, SLSA build provenance, and `workflow_dispatch` dry-run), and `install.sh` with mandatory SHA-256 verification and atomic replacement.

### Fixed

- **External `rg` version probe on Linux**: Added a bounded retry for transient `ETXTBSY` (`ExecutableFileBusy`) errors when probing freshly written or installed `rg` binaries.

### Known limitations

- **Linux glibc baseline**: Prebuilt Linux release archives are built in `ubuntu:22.04` containers and require `glibc >= 2.35` (for example, Ubuntu 22.04+ or Debian 12+); older distributions should build from source.
- **Windows support**: Windows workspace tools, sandbox backend (`run_command` / `search_text`), prebuilt archives, and Windows CI are not yet implemented or verified.
- **Desktop GUI**: Not yet built.
- **Distribution & signing**: No Homebrew tap, Cargo-binstall metadata, or Apple Developer ID signing / notarization yet.
